# Catálogo de proyectos PLP

Cada proyecto tiene una carpeta en `assets/projects/<proyecto>/` y una página informativa en `view/programacion/<proyecto>.html`.

Estructura recomendada:
- `<proyecto>.svg` o `<proyecto>.png`: portada usada en la tarjeta y página.
- `screenshots/`: capturas reales de la aplicación o sitio.
- `downloads/`: instaladores o paquetes públicos, cuando estén disponibles.

No se han añadido enlaces de descarga ficticios. Las páginas indican las plataformas previstas y dejan las descargas pendientes hasta que existan paquetes reales.
